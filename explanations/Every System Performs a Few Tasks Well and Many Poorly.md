# Every System Performs a Few Tasks Well and Many Poorly

Any given system has many functions it can perform only poorly and a few it performs well. The distribution is a property of the system rather than of the ambitions held for it, so it is discovered rather than decided. Knowing which of its tasks fall in the small competent group is what makes the difference between using a system and fighting it.
