# Total Correlation Lets Any Disturbance Re-Trigger the Whole System

When every element of a system responds to every other, there is no boundary at which a disturbance stops. One small input reaches one element, that element reaches the rest, and their reactions return as fresh input. Settling requires that some part of the system be able to stay quiet while another part moves, and total correlation removes that possibility.
