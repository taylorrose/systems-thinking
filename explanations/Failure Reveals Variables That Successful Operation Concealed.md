# Failure Reveals Variables That Successful Operation Concealed

A system can operate successfully while remaining close to a limit no one has identified. The variable becomes visible only when a change crosses that limit and the system fails in a way its known structure did not predict.

The discovery is accidental because the failure supplies the observation that prior analysis did not know to seek.
