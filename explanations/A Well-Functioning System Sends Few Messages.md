# A Well-Functioning System Sends Few Messages

Messages are how a system knows the outside world and its own internal functioning. While tasks are being completed and the system is moving on to the next ones, the number of formal messages stays near a minimum.

A poorly functioning system does the opposite. As unfinished tasks accumulate, it begins generating messages shaped around questions such as what went wrong, how far along a task is, and why the feedback is not better.
