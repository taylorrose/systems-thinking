# A System Once Created Tends to Persist

A system, once established, does not quietly disappear when the occasion for it passes. It displays a remarkable persistence: having acquired one, an organization has it, much as having a baby means having a child thereafter. Persistence is the precondition of growth, because only a system that continues to exist can go on enlarging itself.
