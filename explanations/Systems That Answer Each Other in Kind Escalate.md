# Systems That Answer Each Other in Kind Escalate

When one system responds to another in the same terms, the pair forms what may be called fearful symmetry, a pattern running from sibling rivalry to the nuclear arms race. Its notable feature is a built-in tendency to escalation, which can proceed as far as meltdown. The pattern is avoided only where the second system is unable or unwilling to reply in kind.
