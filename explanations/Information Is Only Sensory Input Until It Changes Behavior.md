# Information Is Only Sensory Input Until It Changes Behavior

Feedback is defined by its effect on the loop, not by its arrival. Information that reaches a system, is displayed, discussed, and filed, but leaves the system's course exactly as it was, has been received without feeding back. Up to the point where behavior changes, it is merely sensory input.
