# Unexplained Trouble Gets Explained Away Instead of Recognized

Someone in this condition still experiences the strange and uncomfortable things that the unrecognized problem produces. Those events are accounted for in all sorts of implausible ways, so each one is absorbed as a local oddity rather than accumulating into evidence that something is wrong.
