# Internal Friction Limits How Hard a System Can Be Driven

Every system carries internal friction among its own parts. That friction sets a ceiling: the force needed to overcome it can exceed the force the parts themselves will bear. Beyond that point, pushing harder is not an available remedy, because the system fails before the push succeeds.
