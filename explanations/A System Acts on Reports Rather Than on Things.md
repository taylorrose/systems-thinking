# A System Acts on Reports Rather Than on Things

A system never handles a thing directly; it handles an account of that thing supplied by whatever channel is allowed to speak to it. Inside its own workings the account and the thing are not held apart, so the description a system receives functions as the thing's identity for every purpose the system serves.
