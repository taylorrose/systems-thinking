# A Thermostat Is Where Self-Reference Is Designed Into a System

A thermostat is the point at which self-reference is deliberately built into a system: the system senses its own state and acts on that reading to hold the state where it was set. Anything the system does to that regulated value is therefore answered by the regulator itself rather than by the outside world.
