# Caring for the Record Is Not the Same as Caring for the Person

A chart is a record of a patient, kept so that the system can act on him. Attending to that record is a different activity from attending to the person it describes, and doing the first well does not entail doing the second at all. A reminder pinned above the console states that difference; it does not close it.
