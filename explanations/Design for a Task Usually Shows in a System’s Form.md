# Design for a Task Usually Shows in a System’s Form

Something genuinely built for a task tends to carry that task in its shape: a hole-digger should probably look something like a shovel. The correspondence is a likelihood rather than a law, and it runs from purpose to form—which is why a visible mismatch between what a system looks like and what it is said to do is worth a second look.
