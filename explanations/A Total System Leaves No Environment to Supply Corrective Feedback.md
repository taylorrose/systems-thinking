# A Total System Leaves No Environment to Supply Corrective Feedback

Correction normally reaches a system from outside it: an environment that resists, refuses, or fails to supply what the system demands. A system that has taken everything inside itself has no such outside left, so there is nothing positioned to register its excesses back to it.
