# Accurate Sensory Input Is Necessary but Not Sufficient

A system can only work with what its senses present to it, so faithful sensory organs are a precondition for any appropriate response. They are not, however, the whole requirement. Input that arrives accurately but incomprehensibly still leaves the system without a basis for choosing what to do.
