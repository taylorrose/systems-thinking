# Relief That Rebounds Worse Than the Original Trouble Is a Positive Feedback Trap

Some remedies relieve a condition briefly and then leave it worse than before. The deepened condition calls for the remedy again, and each round raises the level from which the next rebound starts. Because the output of the loop becomes its own input, the situation escalates rather than settling.
