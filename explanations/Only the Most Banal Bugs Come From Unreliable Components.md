# Only the Most Banal Bugs Come From Unreliable Components

The expectation that bugs will disappear as components become more reliable is wishful thinking. Component unreliability accounts only for the most banal kinds of bug; the rest arise from how the parts are joined and from what the assembled whole lacks, which better parts do not address.
