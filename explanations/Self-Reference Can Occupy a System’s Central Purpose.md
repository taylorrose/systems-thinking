# Self-Reference Can Occupy a System’s Central Purpose

Self-reference is not confined to small quirks or verbal jokes. A system can become self-referential in a big way, with the loop sitting in the very purpose the system exists to serve, so that the condition the system was built to remove is also the condition its existence supplies.

Scale does not dissolve the loop; it enlarges what the loop can do.
