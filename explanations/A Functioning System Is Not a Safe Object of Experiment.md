# A Functioning System Is Not a Safe Object of Experiment

Because a working complex system is a found condition rather than a produced one, there is no assurance that its functioning would survive an alteration or could be restored afterwards. Altering it therefore risks a working condition that may not be recoverable, in exchange for an improvement that is not assured.
