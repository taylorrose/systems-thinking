# An Obsolete System Becomes Work Its Successors Must Keep Doing

A system that has stopped performing its function does not thereby stop existing. It still occupies space, still requires attention, and still has to be contained, maintained, or worked around by whatever replaces it.

The successor therefore inherits the predecessor as part of its own workload. What was once a solution now appears on the far side of the ledger, as a condition the new system must manage rather than a capability it can use.
