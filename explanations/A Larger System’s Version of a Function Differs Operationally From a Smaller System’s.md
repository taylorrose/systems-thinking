# A Larger System’s Version of a Function Differs Operationally From a Smaller System’s

The same divergence appears between systems of different size. In general, a function performed by a larger system is not operationally identical to the function of the same name performed by a smaller one, because the larger system must add steps — storage, transport, selection, standardization — that the smaller one never needed.
