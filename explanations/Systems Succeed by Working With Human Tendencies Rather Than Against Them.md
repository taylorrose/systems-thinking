# Systems Succeed by Working With Human Tendencies Rather Than Against Them

Running downhill, stated in human terms, means designing a system so that its function moves with existing human tendencies instead of resisting them. Where the intended function coincides with what people are already inclined to do, the system is carried by that inclination. Where it opposes the inclination, the same work must be supplied against it.
