# Pathways to Success Can Only Be Found, Not Made

Because systems-behavior follows laws, the route by which a system can be made to work is not something an intervenor invents and imposes. It is something already permitted by those laws and waiting to be located. Effort is better spent searching for the pathway a system will actually allow than on constructing one it will not.
