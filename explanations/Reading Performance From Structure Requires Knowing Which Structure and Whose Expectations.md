# Reading Performance From Structure Requires Knowing Which Structure and Whose Expectations

The claim sounds like common sense until each of its terms is pressed. A machine has many structures, each capable of many performances, and an expectation belongs to whoever holds it. Structure indexes performance only relative to a chosen level of description and to the observer whose expectations are being tested.
