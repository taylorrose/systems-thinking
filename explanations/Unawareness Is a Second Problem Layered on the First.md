# Unawareness Is a Second Problem Layered on the First

A person or system that has a problem and does not realize it carries two problems rather than one: the original problem, and the meta-problem of unawareness. The second problem is what keeps the first one out of reach, and it must be resolved before the first can be worked on at all.
