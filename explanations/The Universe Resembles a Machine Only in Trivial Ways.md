# The Universe Resembles a Machine Only in Trivial Ways

Since the eighteenth century astronomers and cosmologists have pictured the universe as a mechanism. The resemblance holds only in certain trivial ways, so it does not justify the expectation that knowing the universe’s mechanism would make its behavior understandable and predictable.
