# Calling a Condition Inevitable Removes It From Question

A person or system holding the Inevitability-of-Reality Fallacy treats present conditions as necessary simply because they obtain. The condition is then no longer a candidate for change; it is background, part of the way things are, and nothing about it is left to be asked.
