# The Problem Inside the Solution Is Usually the Hardest Part

The part of a problem contributed by its attempted solution is usually the hardest part. This “Problem-in-the-Solution” is elusive enough that, without it, troubleshooting a complex system might eventually be reduced to checking lists in a technical manual.
