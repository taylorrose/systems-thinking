# Whether a Working Complex System Can Be Built From Scratch Is Still Disputed

The claim is not universally accepted. Some observers remain convinced that a working complex system will eventually be found to have been established *de novo*, and mathematicians and engineers in particular may object that the formulation is too sweeping: what it presents as a law of nature, they argue, is only a set of technical difficulties that better methods will overcome. No such exception has yet been produced, so the disagreement is about how the absence should be read rather than about the record itself.
