# Memory Protects Us From Awareness of Failure

Memory has a protective task as well as a recording one: it shields us from more awareness of malfunction than we can comfortably carry. Encounters with systems that failed us drop out of recollection soon after the irritation passes. Because that protective task operates by default, the ordinary state of a person's memory understates how often systems fail.
