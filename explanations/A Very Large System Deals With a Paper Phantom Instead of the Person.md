# A Very Large System Deals With a Paper Phantom Instead of the Person

In a very large system the relationship is never with the individual at all. It is with a Social Security number, a driver’s license, or some other paper phantom derived from one extremely specialized aspect of the person — the only aspect the interface is built to handle.
