# Once Goals Are Fixed, Others Can Deduce and Govern How the Work Is Done

A stated objective makes the route to it deducible. If the goal is settled, the shortest path toward it can be reasoned out by anyone, so hours, methods, and sequence become matters other people can prescribe — and efficiency along that path becomes a second thing to grade.

Called Administrative Encirclement, this is a longstanding pattern rather than a novelty: the administrators, whose original charge was keeping track of supplies for the professors, end up sitting in judgment on their former masters.
