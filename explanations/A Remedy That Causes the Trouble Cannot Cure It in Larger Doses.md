# A Remedy That Causes the Trouble Cannot Cure It in Larger Doses

When the remedy is what deepens the condition, dose is not the variable at fault. Increasing vigor changes the size of the effect but not its direction, so the Nasal Spray Effect cannot be cured by using more nasal spray.
