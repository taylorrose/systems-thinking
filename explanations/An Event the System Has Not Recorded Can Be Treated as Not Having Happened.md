# An Event the System Has Not Recorded Can Be Treated as Not Having Happened

An occurrence enters a system only through the record the system keeps: the official communication, the filed document, the footage. An event that never reaches such a record has no standing there, however plainly it occurred elsewhere, and the system can proceed as though it had never taken place.
