# A Problem Is a Problem Because It Was Wrongly Conceptualized

A problem attains capital-P status precisely because it was incorrectly conceptualized in the first place. The difficulty lies in how the situation has been framed rather than in the situation itself, so no amount of apparatus aimed at the existing framing reaches what makes it a Problem.
