# A Large Enough Machine Behaves Like a Large System

We are accustomed to explaining a system by comparing it to a machine, on the assumption that knowing the mechanism would let us understand and predict the behavior. The comparison runs the other way: a machine that is large and complex enough will itself act like a large system. The familiar metaphor is simply backwards.
