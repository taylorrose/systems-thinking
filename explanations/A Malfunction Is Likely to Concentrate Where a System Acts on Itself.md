# A Malfunction Is Likely to Concentrate Where a System Acts on Itself

When a system malfunctions, the point at which it takes itself as its own object is the point most likely to be generating the trouble. There the system's operation and the result it is meant to produce work against each other, so the fault is a property of the arrangement rather than of any component.

This makes the self-referential point a first place to look rather than a last one, since inspection of the parts can leave such a loop entirely intact.
