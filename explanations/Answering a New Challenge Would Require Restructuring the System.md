# Answering a New Challenge Would Require Restructuring the System

A system may be organized so thoroughly around one familiar response strategy that its structure, equipment, and procedures all presuppose that response. A genuinely new challenge cannot be met by adjusting the response alone; it would require extensive restructuring of the system itself, which systems undertake with the greatest reluctance and difficulty.
