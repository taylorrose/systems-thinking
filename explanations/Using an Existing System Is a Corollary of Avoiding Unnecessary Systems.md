# Using an Existing System Is a Corollary of Avoiding Unnecessary Systems

This rule follows immediately from the rule against multiplying systems. A system already in place has already been brought into being, so putting the job through it adds nothing to the count of systems in play.

The corollary carries significant implications for management, where the choice between putting a job through what already exists and creating something new arises most often.
