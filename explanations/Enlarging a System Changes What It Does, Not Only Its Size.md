# Enlarging a System Changes What It Does, Not Only Its Size

Scaling up a working system is not an additive operation. When the dimensions of a smaller system are expanded, the result is a different system whose behavior does not follow from the behavior of the version it was grown from.

Its size is continuous with the original; its behavior need not be.
