# A System Is Someone’s Solution to a Problem, Not a Solver of Problems

Systems can do many things, but solving problems is emphatically not among them. A system is the form taken by somebody's earlier solution to a problem; it carries out that solution and does not itself solve anything. Yet when a problem is puzzling enough to be treated as a capital-P Problem, people rush to design systems in the hope that a system will solve it.
