# Input Must Be Organized Into a Shape That Suggests a Response

Sensory input becomes usable only when it is assembled into a model of the situation whose form itself indicates what response fits. The organizing work is part of the instrumentation, not something the observer can be assumed to supply afterward. Recognizing the shape of what is happening is therefore a distinct skill from measuring its parts.
