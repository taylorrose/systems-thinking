# A Self-Referential Claim Cannot Be Corrected Inside Its Own Framework

There is no way, within the framework of the system in question, that such a statement can be corrected. The framework supplies the standard of correctness that the statement invokes, so any test conducted inside it returns the statement's own premise.

Correction therefore requires a standard the system does not itself provide.
