# Whether Failure Modes Are Truly Infinite Makes No Practical Difference

Purists and theoreticians may object that the number of ways a system can fail is not truly infinite but merely very large. The objection has theoretical interest and no practical consequence: a merely very large set of failure modes is as far beyond enumeration as an infinite one, so the working conclusion is unchanged either way.
