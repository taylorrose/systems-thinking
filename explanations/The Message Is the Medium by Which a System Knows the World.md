# The Message Is the Medium by Which a System Knows the World

A system has no direct contact with events. What reaches it is a report, and that report is the entire medium through which it registers the world. McLuhan’s formula appears to run the other way around here: the message is not carried by a medium, the message is the medium, since nothing about an event exists for the system except what was reported of it.
