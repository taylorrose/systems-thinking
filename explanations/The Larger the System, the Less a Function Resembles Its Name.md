# The Larger the System, the Less a Function Resembles Its Name

A named function and the work actually performed under that name drift apart as a system grows in size and complexity. In a small setting one person may still perform most of what the name describes; in a large one the name marks a position within the system rather than the activity carried out there. Systemantics calls this paradox Functionary’s Falsity.
