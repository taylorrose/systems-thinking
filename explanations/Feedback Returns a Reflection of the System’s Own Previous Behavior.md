# Feedback Returns a Reflection of the System’s Own Previous Behavior

What arrives as feedback is determined in part by how the system responded on the previous round. The other system answers that response, so the incoming report is an image of the system's own conduct, modified and reflected back through the behavior of whatever it is dealing with. Reading feedback purely as news about the outside world therefore misses the part of it that is an echo.
