# IN DEALING WITH THE SHAPE OF THINGS TO COME, IT PAYS TO BE GOOD AT RECOGNIZING SHAPES

[[explanations/Accurate Sensory Input Is Necessary but Not Sufficient|Accurate sensory input is necessary but not sufficient]], because [[explanations/Input Must Be Organized Into a Shape That Suggests a Response|input must be organized into a shape that suggests a response]].
