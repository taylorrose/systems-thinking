# THE MESSAGE SENT IS NOT NECESSARILY THE MESSAGE RECEIVED

[[explanations/A Receiver Constructs the Message from Their Own Assumptions|A receiver constructs the message from their own assumptions]]; for example, [[examples/An Eighteen-Inch Model Fly Was Received as the Fly’s Actual Size|an eighteen-inch model fly was received as the fly’s actual size]]. Consequently, [[effects/Incidental Features of an Illustration Can Become Part of the Message|incidental features of an illustration can become part of the message]], so [[practices/Check the Message Received Rather Than the Message Sent|check the message received rather than the message sent]].
