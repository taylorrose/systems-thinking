# KNOWLEDGE FOR WHAT?

[[explanations/Knowledge Is Useful Only in the Service of an Appropriate Model|Knowledge is useful only in the service of an appropriate model]]; for example, [[examples/Bacon’s Knowledge Did Not Save Him From Himself|Bacon’s knowledge did not save him from himself]]. Moreover, [[explanations/Pursuing Information as an End Confuses Means with Ends|pursuing information as an end confuses means with ends]], since [[explanations/Counting Information as a Bulk Commodity Ignores Whether a Message Matters|counting information as a bulk commodity ignores whether a message matters]]. For example, [[examples/Agencies Named for Information Accumulate Data Faster Than They Use It|agencies named for information accumulate data faster than they use it]]; consequently, [[effects/Most Accumulated Data Never Reaches a Relevant Question in Time|most accumulated data never reaches a relevant question in time]]. Therefore, [[practices/Ask What Question the Knowledge Is Meant to Answer|ask what question the knowledge is meant to answer]].
