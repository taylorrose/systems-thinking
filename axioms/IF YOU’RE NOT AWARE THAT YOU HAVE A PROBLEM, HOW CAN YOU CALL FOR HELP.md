# IF YOU’RE NOT AWARE THAT YOU HAVE A PROBLEM, HOW CAN YOU CALL FOR HELP?

[[explanations/Unawareness Is a Second Problem Layered on the First|Unawareness is a second problem layered on the first]], because [[explanations/Unexplained Trouble Gets Explained Away Instead of Recognized|unexplained trouble gets explained away instead of recognized]]. Consequently, [[effects/A Problem No One Has Recognized Cannot Be Referred for Help|a problem no one has recognized cannot be referred for help]]; therefore, [[practices/Treat an Implausible Explanation of Trouble as a Sign of an Unrecognized Problem|treat an implausible explanation of trouble as a sign of an unrecognized problem]].
