# THIS SYSTEM IS THE ONLY CORRECT SYSTEM

[[explanations/A System’s Claim to Be the Only Correct System Is a Self-Referential Delusion|A system’s claim to be the only correct system is a self-referential delusion]], and [[explanations/A Self-Referential Claim Cannot Be Corrected Inside Its Own Framework|a self-referential claim cannot be corrected inside its own framework]]; consequently, [[effects/An Uncorrectable Claim of Correctness Can Produce a Runaway at Any Moment|an uncorrectable claim of correctness can produce a runaway at any moment]]. Therefore, [[practices/Test a Claim of Correctness From Outside the System That Makes It|test a claim of correctness from outside the system that makes it]].
