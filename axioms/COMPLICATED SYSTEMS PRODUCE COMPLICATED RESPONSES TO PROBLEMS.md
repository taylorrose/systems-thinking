# COMPLICATED SYSTEMS PRODUCE COMPLICATED RESPONSES TO PROBLEMS

[[explanations/A System Is Someone’s Solution to a Problem, Not a Solver of Problems|A system is someone’s solution to a problem, not a solver of problems]]; however, [[effects/Naming a Problem Invites Experts to Elaborate Its Complexity|naming a problem invites experts to elaborate its complexity]]. Because [[explanations/A Problem Is a Problem Because It Was Wrongly Conceptualized|a problem is a problem because it was wrongly conceptualized]], [[effects/A Large System Built Around a Problem Locks In Its Wrong Conceptualization|a large system built around a problem locks in its wrong conceptualization]], and [[effects/Designing a System to Solve a Problem Yields Two Problems in Place of One|designing a system to solve a problem yields two problems in place of one]]. Therefore, [[practices/Seek a Different Approach Rather Than a Larger System|seek a different approach rather than a larger system]].
