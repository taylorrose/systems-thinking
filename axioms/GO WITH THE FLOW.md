# GO WITH THE FLOW

[[explanations/Systems Succeed by Working With Human Tendencies Rather Than Against Them|Systems succeed by working with human tendencies rather than against them]]. For example, [[examples/A State Lottery Thrives Because It Runs With the Instinct to Gamble|a state lottery thrives because it runs with the instinct to gamble]], whereas [[examples/The Public School System Fails Because It Violates Spontaneity in Learning|the public school system fails because it violates spontaneity in learning]]. Consequently, [[effects/A System That Goes Against the Grain Never Really Succeeds|a system that goes against the grain never really succeeds]]; therefore, [[practices/Align a System’s Function With the Tendencies of the People It Depends On|align a system’s function with the tendencies of the people it depends on]].
