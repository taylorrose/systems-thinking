# THE SOLUTION IS OFTEN PART OF THE PROBLEM

[[explanations/A System Is Someone’s Solution to a Problem, Not a Solver of Problems|A system is someone’s solution to a problem, not a solver of problems]]; consequently, [[explanations/The Problem Inside the Solution Is Usually the Hardest Part|the problem inside the solution is usually the hardest part]], and [[effects/Troubleshooting Complex Systems Cannot Be Reduced to Checking Lists|troubleshooting complex systems cannot be reduced to checking lists]]. Therefore, [[practices/Suspect the Solution When Searching for the Hardest Part of a Problem|suspect the solution when searching for the hardest part of a problem]].
