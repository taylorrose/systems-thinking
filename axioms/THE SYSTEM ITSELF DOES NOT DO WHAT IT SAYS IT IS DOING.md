# THE SYSTEM ITSELF DOES NOT DO WHAT IT SAYS IT IS DOING

[[explanations/A System’s Function Is Not Operationally the Same as a Person’s Function of the Same Name|A system’s function is not operationally the same as a person’s function of the same name]], and likewise [[explanations/A Larger System’s Version of a Function Differs Operationally From a Smaller System’s|a larger system’s version of a function differs operationally from a smaller system’s]]. For example, [[examples/A Supermarket Fresh Apple Is Not the Apple Picked Off the Tree|a supermarket fresh apple is not the apple picked off the tree]], so [[effects/The Larger the Supplying System, the Further the Product Drifts From Its Name|the larger the supplying system, the further the product drifts from its name]]. Therefore, [[practices/Ask at What Scale a Function Is Being Performed|ask at what scale a function is being performed]].
