# ONE SYSTEM’S GARBAGE IS ANOTHER SYSTEM’S PRECIOUS RAW MATERIAL

[[explanations/Discarded Information Can Be Ripening for Another System|Discarded information can be ripening for another system]]; for example, [[examples/Gossip Columnists, Secret Agents, and Some Journalists Work From Garbage Cans|gossip columnists, secret agents, and some journalists work from garbage cans]]. Even when no system has a present use for it, [[effects/Information Useless to Everyone Is Treated as Raw Material for History|information useless to everyone is treated as raw material for history]]; therefore, [[practices/Name the System Before Calling Information Useless|name the system before calling information useless]].
