# IF IT’S WORTH DOING AT ALL, IT’S WORTH DOING POORLY

[[explanations/Striving for Perfection Narrows Attention to a Hypnotic Focus|Striving for perfection narrows attention to a hypnotic focus]]; consequently, [[effects/Perfecting the System at Hand Leaves No Attention for Better Alternatives|perfecting the system at hand leaves no attention for better alternatives]]. For example, [[examples/Napoleon Wrote Opera Regulations While His Army and Empire Hung in the Balance|Napoleon wrote opera regulations while his army and empire hung in the balance]], and [[examples/Philip II Managed Imperial Details While Imported Gold Destroyed Spanish Industry|Philip II managed imperial details while imported gold destroyed Spanish industry]]. Therefore, [[practices/Accept an Imperfect Result Instead of Perfecting the System at Hand|accept an imperfect result instead of perfecting the system at hand]].
