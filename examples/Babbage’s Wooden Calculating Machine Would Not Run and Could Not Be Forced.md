# Babbage’s Wooden Calculating Machine Would Not Run and Could Not Be Forced

Early in the nineteenth century Charles Babbage attempted to build the world's first large calculating machine and made its parts of wood. The machine would not go, and he could not push it hard enough to make it go without breaking it. The discovery of internal friction was neither planned nor welcome.
