# Nasal Spray Relieves Stuffiness and Returns It Worse

Hay fever and “sinus” sufferers use a nasal spray to shrink a stuffy nose. The spray works while it lasts, but when it wears off the rebound stuffiness is worse than the stuffiness that prompted it. The relief and the deterioration come from the same bottle.
