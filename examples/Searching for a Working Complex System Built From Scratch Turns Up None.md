# Searching for a Working Complex System Built From Scratch Turns Up None

The obvious candidates are institutions designed whole and installed at once. The League of Nations does not qualify, and the United Nations qualifies only barely if at all. A diligent search for exceptions of this kind has so far returned negative results.
