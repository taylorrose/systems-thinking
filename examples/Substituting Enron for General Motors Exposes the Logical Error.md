# Substituting Enron for General Motors Exposes the Logical Error

Reading “What’s Good For Enron is Good For The Country” in place of the General Motors version makes the logical error immediately felt. The sentence form is unchanged; only the system named in it has changed, which shows that the form was never carrying the claim.
