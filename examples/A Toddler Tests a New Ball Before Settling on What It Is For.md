# A Toddler Tests a New Ball Before Settling on What It Is For

Give a normally bright toddler a new ball and the toddler chews it, pounds it, and sits on it, quickly finding out what it can be used for. Only then is it used for those purposes. The order matters: the trial comes first and the intended use is read off the results, not asserted in advance.
