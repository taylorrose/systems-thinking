# The Public School System Fails Because It Violates Spontaneity in Learning

The Public School System was founded with the highest and most altruistic goals, yet it remains in a state of chronic failure because it violates the principle of spontaneity in human learning. Its results show the split: it has made literacy universal without making it truly popular.
