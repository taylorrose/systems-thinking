# Garbage Collection Trades One Problem for Many

Before a collection system exists, the immediate problem is what to do with the garbage. Once the system exists, the community must also address labor negotiations, rates and hours, bad-weather collection, truck maintenance, financing, and rules about what collectors will accept.

Some garbage gets collected, but operating the collection system confronts the community with this new set of problems.
