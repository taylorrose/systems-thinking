# A Return to Basic Principles Can Be as Grandiose as a Five-Year Plan

A Return To Basic Principles may be as grandiose as any Five-Year Plan for the Creation of the New Socialist Man. Their political directions differ, but neither direction exempts a plan from the diagnosis of grandiosity.
