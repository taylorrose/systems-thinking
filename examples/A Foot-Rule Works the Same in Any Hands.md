# A Foot-Rule Works the Same in Any Hands

A foot-rule reports the same length whoever picks it up, and nothing has to be learned before its reading can be trusted. The plumb bob and the button and buttonhole system behave the same way: the stability belongs to the arrangement, not to the practice of whoever is using it. Simple systems possessing that attribute of stability do exist.
