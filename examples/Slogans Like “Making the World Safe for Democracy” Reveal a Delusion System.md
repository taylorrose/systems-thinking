# Slogans Like “Making the World Safe for Democracy” Reveal a Delusion System

Phrases such as “creating the new Socialist Man,” “making the world safe for Democracy,” or “better living through asbestos products” can be used to identify the delusion system within which the designers, operators, or managers are working.
