# Static From Nylon Hose Produced Computer Behavior No One Read in the Structure

One of the largest and most sophisticated computers of its day went into convulsions—garbled memory banks, disrupted calculating ability—whenever certain personnel walked nearby. A frantic search traced the cause to electrostatic charges from silk or Nylon hose. Nobody reading the machine's structure had expected that performance from it.
