# A Pushed System Usually Gives One Last Spasm and Then Stops Entirely

Occasionally the parts of a stalled system are so disposed that a good swift kick drops them into place and the system resumes functioning. Ordinarily the same maneuver produces only one last spasmodic effort, after which the system subsides into total immobility.
