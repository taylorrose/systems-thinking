# A System Stops Expanding Only Where Something Else Stops It

Because the checks on expansion are external, the size at which a system settles records the strength of whatever inhibits it rather than any decision to stop. A system that appears content with its present scope may simply be meeting resistance, and its expansion can resume as soon as that resistance weakens.
