# Improving Component Reliability Only Postpones Failure

Early computer engineers found malfunction rising with the fourth power of the number of vacuum tubes, and the preoccupation with reliable components that followed culminated in the microprocessor. Impressive as that is, better components move the day of reckoning later rather than removing it: growth in size and complexity still carries the system past its specifications.
