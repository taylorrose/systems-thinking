# An Intermittent Failure Can Be Ruled Not to Exist

An intermittent failure can be dismissed because it is absent during inspection; for example, [[examples/The FCC Held That Phantom Dialing Does Not Really Exist|the FCC held that Phantom Dialing does not really exist]].
