# A System Built to Improve Performance Can Reduce the Work It Measures

Complying with the measurement consumes the time and attention that the measured work needed, and the resulting program then narrows what may count as work at all: spontaneous impulses, temporary enthusiasms, and unplanned productive turns fall outside it.

Scored against a document he wrote under pressure, a worker can also be recorded as failing while doing valuable work, which gives anyone who wants him gone something to point at.
