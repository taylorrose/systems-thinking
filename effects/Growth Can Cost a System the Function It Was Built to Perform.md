# Growth Can Cost a System the Function It Was Built to Perform

A system that grows and specializes can end up unable to perform the basic task that defined it. The lost capability is not replaced by the new functions that growth brought with it, so the enlarged system may need supporting arrangements simply to accomplish what it once did unaided.
