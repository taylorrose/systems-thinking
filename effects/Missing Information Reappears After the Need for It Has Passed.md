# Missing Information Reappears After the Need for It Has Passed

The item that cannot be found while it is wanted tends to turn up later, once it no longer answers anything. Its return is not the search succeeding; it is the need expiring first.

The searcher therefore spends effort during the window when the information would have mattered and receives it during the window when it would not.
