# A Fail-Safe System Fails in a Form No One Anticipated

Because the safety apparatus is designed against the failure modes already imagined, the failure that arrives is one outside that set. A project conceived as an infallible fail-safe system is therefore predictable in one respect only: it will fail, and it will do so in a way that was not anticipated.
