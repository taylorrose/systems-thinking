# Grander Systems Display Grander Design Faults

Bad design does not stay proportionate to the modesty of a project. The more grandiose the system, the more grandiose the faults tend to be that are visible in it, to the point where a central component can both threaten the system carrying it and defeat the mission it was installed to perform.
