# A Function Persists After the Need for It Has Disappeared

Because circumstances do not govern continuation, the disappearance of a purpose can leave the activity serving it in place. The routine goes on after the condition that once justified it has gone.

The activity's continuation is therefore no evidence that a need for it remains.
