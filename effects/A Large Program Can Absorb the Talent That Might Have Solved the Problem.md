# A Large Program Can Absorb the Talent That Might Have Solved the Problem

A system that is sufficiently large, complex, and ambitious can drive output far below random levels, because everyone's attention is now fixed on making the existing system work. A federal program to conquer cancer may in this way tie up the competent researchers in the field, leaving the problem to be solved by someone outside it.
