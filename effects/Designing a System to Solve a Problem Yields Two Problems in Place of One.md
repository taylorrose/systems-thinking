# Designing a System to Solve a Problem Yields Two Problems in Place of One

Designing a system in the hope that the system will somehow solve a problem, rather than solving the problem in the first place, presents one with two problems instead of one: the original problem, still unsolved, and the new system that now has to be made to work.
