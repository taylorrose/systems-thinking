# Dismantling a Failed System Becomes Its Own New Problem

Among the new problems a system creates, one is almost certain to appear promptly: taking the system apart once it has shown that it cannot perform. The failure of the system does not end the commitment to it, because getting out is now a separate piece of work with its own cost.
