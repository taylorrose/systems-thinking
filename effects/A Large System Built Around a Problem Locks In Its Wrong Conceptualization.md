# A Large System Built Around a Problem Locks In Its Wrong Conceptualization

A large system for studying and attacking a problem fixes the erroneous conceptualization in the minds of everyone concerned. This approach guarantees failure for all but the most pedestrian tasks, since the effort now defends the framing that made the problem intractable.
