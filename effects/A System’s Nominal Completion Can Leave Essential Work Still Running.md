# A System’s Nominal Completion Can Leave Essential Work Still Running

When a system reports that a journey or an operation is finished, the remaining distance or the remaining process does not disappear with the announcement. What is left over still has to be travelled, cooled, or attended to, and in some settings failing to continue that work invites disaster.
