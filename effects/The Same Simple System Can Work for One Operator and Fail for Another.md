# The Same Simple System Can Work for One Operator and Fail for Another

Where stability depends on skill in operation, the outcome moves with the person operating the system. The same equipment performs for a practiced user and misbehaves for an unpracticed one, so “it works” describes a pairing of system and operator rather than a property of the design alone. A record of successful use elsewhere therefore need not carry over to new hands.
