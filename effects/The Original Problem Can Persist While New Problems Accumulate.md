# The Original Problem Can Persist While New Problems Accumulate

In really large and ambitious systems the original problem may survive unchanged, so the redistribution never arrives. At the same time a multitude of new problems can arise and remain unresolved, leaving the community with the whole of what it started with plus everything the system now requires.
