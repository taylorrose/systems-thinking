# Avoid Setting Up a System Whose Operation Recreates the Problem It Addresses

Before establishing a system, state the condition it is meant to reduce and then trace what its normal operation supplies. Ask whether operating it generates the need, hazard, or demand it targets, and whether the system would have less to do if it were doing less.

Where the answer is yes, prefer an arrangement that does not take its own output as its input, and count yourself among the parties the loop can capture: the warning applies to the designer and the observer, not only to the system on the page.
