# Treat an Enlarged System as an Untested New System

When a system is to be built by expanding the dimensions of one that already works, do not carry the smaller system’s track record forward as evidence. Treat the larger version as a system whose behavior is not yet known.

Ask which properties were established by operating the original and which were merely assumed to scale. Then observe the enlarged system on its own terms — how it actually behaves under load, and how it actually fails — rather than checking whether it matches the smaller system’s record.
