# Ask at What Scale a Function Is Being Performed

Before accepting that a function is being performed, establish the size of the system performing it. Ask whether the work is being done by a person, by a small system, or by a large one, and list the operations each would have to add to deliver the result.

Expect the same name to cover different operations at each scale, and compare the versions rather than the name they share.
