# Check Whether Escalating Effort Is Producing More of the Behavior You Want to Remove

Before increasing effort on a stubborn result, compare the unwanted behavior now with its level before the last increase. If more effort has been followed by more of the behavior you were trying to remove, treat the added effort as an input to that behavior rather than as a remedy for it.

Then name what the effort itself contributes: the attention it supplies, the response it provokes, or the activity it substitutes for the result. Change or withdraw that contribution instead of raising the level again, and reserve the explanation that you have not tried hard enough until the loop has been ruled out.
