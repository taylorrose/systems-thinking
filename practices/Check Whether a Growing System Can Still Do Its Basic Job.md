# Check Whether a Growing System Can Still Do Its Basic Job

When a system is being enlarged or made more capable, name its elementary tasks first and test them separately from its new ones. Ask which of those tasks it could once perform unaided, what conditions it now requires to perform them, and what supporting arrangements have quietly appeared to compensate.

Treat a basic function that now needs special conditions as a loss rather than a detail, and decide whether the added capability is worth it.
