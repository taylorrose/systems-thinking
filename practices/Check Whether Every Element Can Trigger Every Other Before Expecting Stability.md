# Check Whether Every Element Can Trigger Every Other Before Expecting Stability

When looking for a stable configuration, map which elements can send signals to which others, and look for cycles in which a reaction returns to its own origin as new input. Ask whether any element is free to stay quiet while its neighbours move.

Where the map shows everything coupled to everything, expect no settled state until some couplings are removed, damped, or delayed. Prefer to do this mapping in the design stage, while couplings are still cheap to change.
