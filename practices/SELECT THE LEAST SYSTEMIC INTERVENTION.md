# SELECT THE LEAST SYSTEMIC INTERVENTION

Begin with restraint. If [[axioms/IF A SYSTEM IS WORKING, LEAVE IT ALONE. DON’T CHANGE ANYTHING|the system works, leave it alone]]. Apply [[axioms/AVOID UNNECESSARY SYSTEMS (SYSTEMS SHOULD NOT BE MULTIPLIED UNNECESSARILY)|system avoidance as the default]] and prefer, in order, to [[axioms/DO IT WITHOUT A NEW SYSTEM IF YOU CAN|act without a new system]], [[axioms/DO IT WITH AN EXISTING SYSTEM IF YOU CAN|use an existing system]], or [[axioms/DO IT WITH A SMALL SYSTEM IF YOU CAN|use a small system]]. Ask whether [[axioms/SOME THINGS JUST CAN’T BE DONE WELL BY A SYSTEM|the goal belongs outside systems]]. Reject [[axioms/PUSHING ON THE SYSTEM DOESN’T HELP|pressure as leverage]] and [[axioms/BAD DESIGN CAN RARELY BE OVERCOME BY MORE DESIGN, WHETHER GOOD OR BAD|elaboration as repair]]. If the present action fails, [[axioms/IF SOMETHING ISN’T WORKING, DON’T KEEP DOING IT. DO SOMETHING ELSE INSTEAD|stop repeating it]] or [[axioms/DO ALMOST ANYTHING ELSE|break the pattern]].

Locate the level before selecting the move. Apply [[axioms/IN ORDER TO BE EFFECTIVE, AN INTERVENTION MUST INTRODUCE A CHANGE AT THE CORRECT LOGICAL LEVEL|change at the producing level]]. If [[axioms/IF YOUR PROBLEM SEEMS UNSOLVABLE, CONSIDER THAT YOU MAY HAVE A META-PROBLEM|the problem is meta-level]], move upward; if ordinary remedies fail, [[axioms/WHEN PROBLEMS DON’T YIELD TO COMMONSENSE SOLUTIONS, LOOK FOR THE THERMOSTAT|locate the controlling relationship]]. Find practical leverage where [[axioms/CONTROL IS EXERCISED BY THE ELEMENT WITH THE GREATEST VARIETY OF BEHAVIORAL RESPONSES|response variety is greatest]], not merely where authority is named.

Use existing affordances before adding structure. [[axioms/UTILIZE THE PRINCIPLE OF UTILIZATION|Start with demonstrated capability]]. Check that [[axioms/(A) IF IT’S FOR DIGGING A HOLE IT SHOULD PROBABLY LOOK SOMETHING LIKE A SHOVEL|form fits the intended function]], then test whether [[axioms/(B) IF IT LOOKS LIKE A SHOVEL, TRY USING IT FOR DIGGING A HOLE|available form can perform it]].

Test reachability and learning cost. When [[axioms/IN THE MAJORITY OF CASES, YOU CAN’T GET THERE FROM HERE|the current state cannot reach the goal]], alter the starting condition or the goal. Remember [[axioms/PROBING WILL GET YOU ONLY SO FAR|probes have limits]] and [[axioms/THE SYSTEM IS ALTERED BY THE PROBE USED TO TEST IT|a probe changes its target]]. Therefore [[axioms/ALWAYS ACT SO AS TO INCREASE YOUR OPTIONS|increase future options]] rather than obeying the impossible instruction to [[axioms/ALWAYS MAKE CORRECT DECISIONS|always decide correctly]].

Before acting, confirm the leverage model from different evidence: [[axioms/THE FUNCTION (OR PRODUCT) IS DEFINED BY THE SYSTEMS-OPERATIONS THAT OCCUR IN ITS PERFORMANCE OR MANUFACTURE|operations reveal function]], [[axioms/SYSTEMS DEVELOP GOALS OF THEIR OWN THE INSTANT THEY COME INTO BEING|systems redirect action toward their own goals]], and [[axioms/THE MEANING OF A COMMUNICATION IS THE BEHAVIOR THAT RESULTS|communication means the behavior produced]]. Call the move effective only when [[axioms/IT HASN’T FED BACK UNTIL THE SYSTEM CHANGES COURSE|observed behavior changes course]].
