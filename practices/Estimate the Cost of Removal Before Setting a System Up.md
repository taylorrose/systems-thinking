# Estimate the Cost of Removal Before Setting a System Up

While a system is still being proposed, work out what taking it down would involve. Ask who would have to be trained or equipped to do it, what would first have to be located, and what the removal would cost relative to the installation.

Record where each part is put as it goes in, so a later removal does not begin with a search. Where the removal cannot be costed or the placement cannot be tracked, treat that as part of the price of setting the system up.
