# Treat an Implausible Explanation of Trouble as a Sign of an Unrecognized Problem

When the account of why something odd happened requires unusual coincidence, special circumstances, or an explanation that would embarrass you to repeat, note it rather than accept it. Collect such episodes instead of settling each one separately.

Then ask what single unrecognized condition would explain the whole set at once. Naming that condition is what makes it possible to ask anyone for help with it.
