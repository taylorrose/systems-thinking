# Align a System’s Function With the Tendencies of the People It Depends On

Before committing to a design, name the human tendencies the system will actually run on: what the participants are already inclined to do without being urged. Then ask whether the intended function moves with those inclinations or has to overcome them.

Where the function runs against them, treat the mismatch as a design problem rather than a motivation problem, and look for a formulation of the same purpose that the existing tendencies would carry.
