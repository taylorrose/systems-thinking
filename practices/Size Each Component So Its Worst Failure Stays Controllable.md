# Size Each Component So Its Worst Failure Stays Controllable

At the level of ordinary design and management, set limits on each component by asking what its complete failure would release. Keep no single storage or holding unit large enough to harm everyone exposed to it, and none so large that the crew on hand could not bring a failure back under control.

Apply the same sizing question wherever a quantity is concentrated for convenience, and take an answer you cannot bound as a reason to divide the quantity rather than to add safeguards around it.
