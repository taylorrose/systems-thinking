# Start Over From a Working Simple System Rather Than Repairing a From-Scratch Design

When a complex system was designed whole and does not work, treat further repair as unlikely to reach function. Ask instead what the smallest version of the system would be that actually works, build or find that, and let the larger system grow from it.

Applying this means giving up sunk effort deliberately: identify which parts of the failed design describe a working simple system and which exist only because the whole was drawn at once. Keep the first, discard the second, and add complexity only after the smaller system is observed working.
