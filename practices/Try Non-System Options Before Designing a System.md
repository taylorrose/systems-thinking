# Try Non-System Options Before Designing a System

Before drafting a system, look for a way to get the job done without one. Ask whether the result can be reached by a direct action, an occasional arrangement, or a change in what is asked for, and try those first.

Design a system only when the work cannot be done adequately through those simpler routes. Preserve the axiom’s qualification: avoiding a new system is preferred when it is possible, not when doing so prevents the work from being done.
