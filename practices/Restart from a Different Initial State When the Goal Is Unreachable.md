# Restart from a Different Initial State When the Goal Is Unreachable

Before continuing to manipulate a system toward a goal, ask whether the goal is reachable from the state the system is in at all. Look for evidence that repeated effort is exploring the same accessible set rather than closing on the target.

When the goal appears to lie outside that set, stop manipulating and change the starting point instead. Ask which initial states would make the goal accessible, what it would cost to get into one, and whether that cost is lower than continued effort from here. Treat the choice of starting state as part of the work rather than as something already settled.
