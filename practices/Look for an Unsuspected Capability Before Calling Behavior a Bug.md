# Look for an Unsuspected Capability Before Calling Behavior a Bug

When a system does something no one planned, hold off on the label. Ask whether any error in design or construction is actually identifiable, and if none is, describe the behavior as a capability the structure already had.

Then record what in the surroundings brought it out, so the same conditions can be recognized the next time.
