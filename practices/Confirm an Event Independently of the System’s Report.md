# Confirm an Event Independently of the System’s Report

When a system asserts that something happened, treat the assertion as a report rather than as the event. Ask who observed it, when the record was made, and whether the record could have been produced before or without the event occurring.

Then look for evidence that did not pass through the same intake: a direct observation, a party outside the reporting chain, or a physical trace. Accept the system’s account as the event only when something outside the system’s own channel agrees with it.
