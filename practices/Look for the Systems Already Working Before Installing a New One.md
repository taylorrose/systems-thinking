# Look for the Systems Already Working Before Installing a New One

Before a new system is put in place, identify what is already operating in the same space and what each of those arrangements currently accomplishes. Ask which resources, channels, or thresholds the new system will share with them, and how each will behave when the other reaches for the same thing.

Then introduce the new system gently enough that such contact can be observed and reversed. Treat an existing arrangement as working until shown otherwise, since the disturbance you cause may fall on the part that was working.
