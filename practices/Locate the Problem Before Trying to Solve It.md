# Locate the Problem Before Trying to Solve It

When effort is producing no solution, suspend the search for a better solution and ask where the problem is. Check each candidate location in turn: are the probes inadequate to elicit the behavior wanted, is the trouble the designed functioning of the system itself, or was the problem formulated badly to begin with?

Name the level at which the problem is being addressed and the level at which the responsible behavior is produced. If they differ, relocate the problem before resuming work on it.
