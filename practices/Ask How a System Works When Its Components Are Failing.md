# Ask How a System Works When Its Components Are Failing

Set aside the description of the system operating well and put the pertinent questions instead: how does it work when its components are not working well, how does it fail, and how well does it work in failure mode?

Answer them concretely—which functions survive degradation, which are lost first, and what the system still delivers while impaired. Since impaired operation is the usual condition of a large system, that answer describes its real behavior rather than an exception to it.
