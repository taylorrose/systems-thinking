# Record What Each Bug Tells You About How the System Can Fail

When a fault appears, treat it as a report before treating it as a nuisance. Write down the condition under which it showed itself, the behaviour it produced, and the failure mode it therefore demonstrates the system is capable of.

Keep that entry after the fault is fixed, since the repair removes the instance and not the mode. Review the accumulated list when planning or changing the system, and read it as a description of where this system tends to break rather than as a history of past annoyances.
