# Treat the First System as a Draft You Will Replace

Plan the first build as something to be scrapped, since it is likely to be scrapped whether or not it was planned that way. Budget the schedule, the money, and the commitments so that discarding it remains affordable, and keep the design cheap to abandon rather than elaborate enough to defend.

Use the first system to learn where the design is wrong, and hold back the effort that a replacement will need. Avoid arrangements — names, promises, dependent systems — that make replacement more expensive than continuing with a design already known to be faulty.
