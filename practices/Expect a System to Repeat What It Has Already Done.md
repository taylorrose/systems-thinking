# Expect a System to Repeat What It Has Already Done

When anticipating a system's behavior, start from its history rather than from its description. Ask what it has actually produced before in comparable situations, and take that as the default expectation.

Weigh announcements of new behavior against that baseline rather than in place of it. Give up the expectation of repetition only for a behavior the system has since demonstrably stopped.
