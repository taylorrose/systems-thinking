# Preserve the Ability to Stop a System Before Livelihoods Depend on Its Growth

Before expanding a system, identify which livelihoods and essential functions will become dependent on its continued operation. Keep a path for supporting them that does not require the system to grow again.

Recheck that exit path at each expansion. If stopping now would impose more immediate suffering than another round of growth, the system is already entering the condition this practice is meant to prevent.
