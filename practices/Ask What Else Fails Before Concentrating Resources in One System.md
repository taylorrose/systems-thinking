# Ask What Else Fails Before Concentrating Resources in One System

Before committing a large share of available resources to a single system, describe the failure that follows from its loss. Ask how much of the whole depends on it, what would remain if it stopped, and which ongoing needs are going unfunded while it is built.

Compare that against the same resources divided among smaller arrangements, where one failure does not reach everything.
