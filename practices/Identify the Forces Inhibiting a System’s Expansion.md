# Identify the Forces Inhibiting a System’s Expansion

Instead of asking whether a system wants to grow, ask what is currently preventing it. Name the specific inhibitors—budgets, statutes, competitors, physical limits, the attention of someone able to refuse—and note which of them are durable and which depend on present circumstances.

When a limit is expected to hold, know what maintains it. When an inhibitor is weakening or about to be removed, treat renewed expansion as the likely result.
