# Suspect the Solution When Searching for the Hardest Part of a Problem

When a problem resists diagnosis, add the arrangement installed to solve it to the list of suspects rather than treating it as the fixed ground of the search. Ask which present difficulties exist only because that arrangement is in place and what would remain if it were absent.

Expect this candidate to be difficult to recognize: the solution is often part of the problem and that part is usually the hardest.
