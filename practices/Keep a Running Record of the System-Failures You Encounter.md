# Keep a Running Record of the System-Failures You Encounter

Note each occasion on which a system you dealt with failed to do what it is advertised to do. Record what was promised, what actually happened, and where the two parted company.

Keep the record for a stretch of days rather than for a single incident, since the value comes from the accumulated count rather than from any one entry. Treat entries as data about how systems behave, not as grievances to be settled.
