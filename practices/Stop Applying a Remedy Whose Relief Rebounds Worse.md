# Stop Applying a Remedy Whose Relief Rebounds Worse

Before adopting a remedy, ask what happens when it wears off, not only what happens while it works. Compare the condition after each cycle with the condition before the first one.

If the trend across cycles is upward, break the loop by stopping the remedy rather than by timing the next dose better.
