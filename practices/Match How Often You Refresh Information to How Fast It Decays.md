# Match How Often You Refresh Information to How Fast It Decays

For each item a decision rests on, estimate how long it stays useful, then set the interval at which it is renewed to something shorter than that span. The more urgent the item, the tighter the interval has to be.

Compare that interval against how long the system actually takes to deliver and act on the item. Where delivery is slower than decay, either shorten the path or stop treating the item as current.
