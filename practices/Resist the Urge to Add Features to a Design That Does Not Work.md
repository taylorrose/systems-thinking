# Resist the Urge to Add Features to a Design That Does Not Work

When something newly built refuses to function, notice the impulse to make it go by adding to it, and stop before acting on it. Ask whether the proposed accessory, feature, or appendage addresses the arrangement that is failing, or merely presses harder on it.

If the addition only presses harder, withhold it. Treat the failure as information about the design rather than as a gap to be filled, and reopen the design instead of extending it.
