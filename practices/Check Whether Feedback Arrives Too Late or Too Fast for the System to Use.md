# Check Whether Feedback Arrives Too Late or Too Fast for the System to Use

Before treating a feedback channel as adequate, measure its timing against two separate clocks. Ask how long the loop takes from event to report to response, and whether the events being reported change faster than that.

Then ask how much the system can actually take in and act on within its own response cycle. A channel that outruns that capacity needs reducing or aggregating just as a lagging channel needs shortening.
