# Justify Each Additional System Before Adding It

Count the systems already in play, then require the proposed one to show what it adds that none of them supplies. State the necessity in terms of the specific work that would otherwise go undone.

Where no such necessity can be stated, drop the addition rather than keeping it for tidiness, symmetry, or completeness. Apply the same test to each further system, so that necessity is established one at a time instead of inherited from the first.
