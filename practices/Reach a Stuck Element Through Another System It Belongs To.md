# Reach a Stuck Element Through Another System It Belongs To

When an element will not move within the system you are working in, stop pressing on it there and list the other systems it also belongs to. For each one, ask what that system already does to the element, what would have to be true for it to move the element in the direction you want, and whether you can act inside that system at all.

Then intervene where the leverage exists rather than where the problem was first stated. Expect the search itself to be uncertain: a route may not be found, and no method guarantees one.
