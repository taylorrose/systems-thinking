# Leave Slack in a System Rather Than Winding It Tight

Build and run a system with deliberate play in it: tolerance between the parts, margin in the schedule, and less than the maximum tension the design would bear. Treat that slack as part of the specification rather than as waste to be tuned away.

When the system resists, read the resistance as a limit rather than as a call for more force. Ask where the tightness is, and loosen it, before attempting to push the system through it.
