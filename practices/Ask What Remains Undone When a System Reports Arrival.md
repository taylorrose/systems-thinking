# Ask What Remains Undone When a System Reports Arrival

Treat a system’s report of arrival, shutdown, or completion as a statement about the system’s own state. Ask which named goal that state was supposed to stand for, what distance or process still separates the two, and who is responsible for the remainder.

Then decide what must keep running after the announcement. Accept the report as completion only when nothing consequential is still in motion behind it.
