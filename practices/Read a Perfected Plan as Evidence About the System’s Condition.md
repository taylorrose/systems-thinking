# Read a Perfected Plan as Evidence About the System’s Condition

When a system presents a finished plan, a completed headquarters, or an elaborate program, date it. Ask when the situation it answers arose, how long the perfecting took, and what has changed in the interval.

Then ask what the system did about the problem while the plan was being perfected. Where the plan is the principal thing accomplished, read the polish as information about the system’s stage rather than as a measure of its capability.
