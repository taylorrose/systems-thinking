# Propose Only Reframings That Benefit Every Party

Before offering a new frame, name every party affected and state how the proposal is genuinely beneficial to each. Include costs and losses rather than treating any benefit as proof that the whole change is beneficial.

If the proposal is an attempt to exploit one party, withdraw it rather than disguising it as reframing. The exploitation will eventually be recognized and provoke destructive kickback.
