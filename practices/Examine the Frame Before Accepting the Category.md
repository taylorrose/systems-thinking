# Examine the Frame Before Accepting the Category

When a system presents a category as obvious, identify the boundary the name creates. Ask what it includes, what it excludes, which observations it makes salient, and which responses it makes seem appropriate.

Then test whether the situation becomes more intelligible or tractable under a different distinction. Keep the category only when its frame improves contact with what the system actually does.
