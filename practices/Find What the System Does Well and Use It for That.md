# Find What the System Does Well and Use It for That

Begin by finding out, by trial rather than by charter, which tasks the system actually performs well. Note what it completes reliably, what it degrades, and what it only appears to do because someone outside it is compensating.

Then assign it the tasks in the first group and route the rest elsewhere. When a needed task falls outside what the system does well, treat that as a reason to look for a different system rather than as a performance problem to be pressed harder.
