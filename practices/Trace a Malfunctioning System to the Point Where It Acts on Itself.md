# Trace a Malfunctioning System to the Point Where It Acts on Itself

When a system malfunctions, map its operation until you find where an output re-enters as an input, where a remedy is applied to the condition it produces, or where the system measures, corrects, or describes itself. Mark each such point before examining components.

Then ask, at each point, whether the system's own activity there is producing the result being complained about. Work on the loop you find rather than on the part that failed most visibly, and treat the absence of any self-referential point as a reason to look for a different class of cause.
