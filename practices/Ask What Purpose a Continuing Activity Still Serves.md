# Ask What Purpose a Continuing Activity Still Serves

Take an activity a system performs routinely and name the condition that originally called for it. Then check whether that condition still holds.

Where it does not, treat the activity's continuation as inertia rather than as evidence of a need, and do not infer a current purpose from the fact that the work is still being done. Apply the question to established routines rather than only to new ones, since long standing is what makes the original justification hardest to recall.
