# Check Whether Trying Again Means a New Attempt or the Same Failing One

Before repeating an effort, state what will be different about this attempt: a different problem, different resources, different timing, or a different method. If nothing on that list changes, the attempt is a repetition rather than a new try.

Count how many times the same unchanged attempt has already been made, and treat a rising count as evidence about the approach rather than about your resolve.
