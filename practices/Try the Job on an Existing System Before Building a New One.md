# Try the Job on an Existing System Before Building a New One

List the systems already running that touch the work, and check each for whether it can carry the job as it stands or with a modest adjustment. Ask what the new system would do that none of them can be made to do.

Where an existing system can take the work adequately, assign it there. Reach for a new one when the existing options cannot carry the job, preserving the axiom’s qualification rather than demanding a trial that would serve no purpose.
