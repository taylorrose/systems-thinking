# NAME THE EFFECT AND DEFINE SUCCESS

Begin before the problem statement. Name the observable effect, the people who should experience it, the time horizon, and the evidence that would count. Challenge any claim that [[axioms/THINGS HAVE TO BE THE WAY THEY ARE AND NOT OTHERWISE BECAUSE THAT’S JUST THE WAY THEY ARE|the present arrangement is necessary]]. Confirm an accountable request, because [[axioms/IF YOU’RE NOT AWARE THAT YOU HAVE A PROBLEM, HOW CAN YOU CALL FOR HELP|an unrecognized problem cannot request help]], and ask whether [[axioms/IF YOU’RE NOT THERE, THE ACCIDENT CAN HAPPEN WITHOUT YOU|leaving removes the exposure]].

Define success in operations, using [[axioms/THE FUNCTION (OR PRODUCT) IS DEFINED BY THE SYSTEMS-OPERATIONS THAT OCCUR IN ITS PERFORMANCE OR MANUFACTURE|actual production as the measure]]. Ask [[axioms/KNOWLEDGE FOR WHAT|what decision the evidence changes]] and remember that [[axioms/WHEN YOU GET THERE, YOU’RE STILL NOT THERE|arrival may not complete the work]]. Separate contribution from [[axioms/THE SYSTEM TAKES THE CREDIT (FOR ANY FAVORABLE EVENTUALITY)|institutional credit-taking]], and refuse to treat [[axioms/WHAT’S GOOD FOR GENERAL SYSTEMANTICS IS GOOD FOR THE COUNTRY|benefit to the system as benefit to everyone]].

Bound the intended change. Record adjacent effects because [[axioms/(A) YOU CAN’T CHANGE JUST ONE THING|one change affects other things]], exclusions because [[axioms/(B) YOU CAN’T CHANGE EVERYTHING|not everything can be changed]], and assumptions because [[axioms/DESTINY IS LARGELY A SET OF UNQUESTIONED ASSUMPTIONS|unquestioned premises narrow the future]]. Treat [[axioms/PROBLEMS ARE NOT THE PROBLEM; COPING IS THE PROBLEM|coping capacity as part of success]].

Only then test means. Prefer to [[axioms/DO IT WITHOUT A NEW SYSTEM IF YOU CAN|avoid a new system]], then [[axioms/DO IT WITH AN EXISTING SYSTEM IF YOU CAN|use what already works]], and [[axioms/CHOOSE YOUR SYSTEMS WITH CARE|choose deliberately]] only if required. Define disconfirming evidence: [[axioms/IF AT FIRST YOU DON’T SUCCEED, TRY, TRY AGAIN|repetition must produce new learning]]. When it does not, [[axioms/IF SOMETHING ISN’T WORKING, DON’T KEEP DOING IT. DO SOMETHING ELSE INSTEAD|stop repeating the failure]] or [[axioms/DO ALMOST ANYTHING ELSE|break the pattern]]. Preserve permission to [[axioms/FOR MAXIMUM SUCCESS, FEEL FREE TO SWITCH SYSTEMS AND EVEN TO SWITCH GOALS|change means or ends]] and, when necessary, [[axioms/IF YOU CAN’T CHANGE THE SYSTEM, CHANGE THE FRAME—IT COMES TO THE SAME THING|change the frame]].
