# Determine Whether a Big System Already Works Before Committing to Make It Work

Establish first whether the system is functioning on its own. Ask what it currently delivers without intervention, and for whom — a system can work very well for someone other than the person it was said to serve.

If it is not working on its own, treat the effort required to make it work as unlikely to pay, and spend the deliberation on other options instead of on a campaign to make this system function.
