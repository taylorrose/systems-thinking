# Treat a System’s Purpose as Whatever It Can Be Used For

Rather than asking what a system is ultimately for, retreat to a down-to-earth question: what can this system actually be used for? Establish what it reliably does, who can put that to use, and under what conditions, and let that inventory stand as its purpose.

This keeps attention on observable capacity instead of declared intent, and it holds when the declared intent is unavailable, disputed, or unknowable.
