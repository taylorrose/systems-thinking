# Ask Whether the Problem Can Be Avoided Before Engaging It

Before committing effort to a stubborn problem, look for the toe-hold you would work from. If there is none, ask what would happen if you were simply not there for it: whether the occasion can be let go, the schedule allowed to slip, or the involvement declined.

Compare that against the cost of engaging, including the wreckage a failed attempt would leave behind. Choose avoidance deliberately and on the record, so that it stays a decision rather than becoming a retreat.
