# State What You Originally Wanted Before Judging What a System Delivers

Write down the want in its own terms — the qualities and conditions that would satisfy it — before looking at what the system offers. Do this without using the system’s product name, since that name carries the system’s own answer.

Then compare the offering against the written want rather than against the system’s description of itself. Where the want has quietly been rewritten to match the output, the apparent success belongs to the naming, not to the system.
