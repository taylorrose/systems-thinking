# Expect Functions You Did Not Design Whenever You Add Structure

Treat added structure as bringing functions beyond the ones specified, and plan on discovering some of them late. Ask what the new arrangement now makes possible that the old one did not, and keep the question open after the work is judged finished.

Leave room in schedules and expectations for capabilities that appear only when circumstances change.
