# Expect Malfunction as a Standing Condition

Take poor function as the ordinary starting state rather than as news. Before asking what went wrong recently, ask whether the thing in question ever worked as expected, and whether the same complaint has been raised about it before.

Where the complaint turns out to have been continuous, treat the condition as one to be lived with rather than as a defect still awaiting removal, and set expectations accordingly.
