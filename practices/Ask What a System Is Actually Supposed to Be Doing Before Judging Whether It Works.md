# Ask What a System Is Actually Supposed to Be Doing Before Judging Whether It Works

Before calling a system successful or failing, state the function you are judging it against and name what would count as evidence of that function being performed. Then ask which of the competing accounts of its purpose you have adopted, and whether the verdict would change under another one.

Distinguish that evidence from the system's presentation of itself. Names, structures, buildings, and reports can persist unchanged through malfunction, so treat them as claims about function rather than as observations of it.
