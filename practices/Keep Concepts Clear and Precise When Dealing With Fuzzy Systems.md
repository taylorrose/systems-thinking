# Keep Concepts Clear and Precise When Dealing With Fuzzy Systems

State plainly what each term in a description refers to, which observations would count for it, and which would count against it. Where a boundary is genuinely indistinct, say so explicitly instead of leaving the vagueness inside a term that sounds definite.

Re-examine any account of a system that survives only because nobody has asked what its words mean. Precision here is about the description, not about pretending the system itself has sharp edges.
