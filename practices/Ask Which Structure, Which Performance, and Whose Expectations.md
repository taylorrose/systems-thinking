# Ask Which Structure, Which Performance, and Whose Expectations

When someone predicts what a system will do from the way it is built, make the three terms explicit. Name the level of structure being read, the specific performance being predicted, and the person whose expectation is at stake.

Treat a prediction that cannot answer all three as a statement about the predictor rather than about the system.
