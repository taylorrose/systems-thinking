# Account for the Messages You Send by Doing Nothing

When deciding to stay silent, delay, or leave something unfilled, treat that as a message you are sending rather than as an abstention. Ask what the omission is likely to be read as by each party who will notice it.

Extend the same question to whatever you leave standing without explanation. If the reading you expect is not the one you want, silence will not prevent it; only sending something else may.
