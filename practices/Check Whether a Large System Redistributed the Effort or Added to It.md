# Check Whether a Large System Redistributed the Effort or Added to It

Before crediting a system with solving anything, ask what happened to the original demand for effort. Is it gone, has it changed form and location, or is it still there in full while the system's own requirements sit on top of it?

Then ask the counterfactual for each new burden: would this condition have existed without the system, and is it now worse because the system exists? Treat exponential growth in total effort as a live possibility at large scale rather than assuming that size only spreads the load.
