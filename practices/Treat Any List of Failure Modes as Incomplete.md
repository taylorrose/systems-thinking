# Treat Any List of Failure Modes as Incomplete

When a set of failure modes has been catalogued, do not treat the catalogue as the boundary of what can go wrong. Ask what the list assumes about how the system will be used, which combinations of failures it omits, and what it would take for the system to fail in a way nobody wrote down.

Keep the list for the failures it does cover, and keep separate provision for the ones it cannot. Because the ways a system can fail exceed enumeration, a plan that depends on the list being complete is depending on the one property it cannot have.
