# Name the System Before Calling Information Useless

When information looks spent, say which system it is spent for. State the questions that system was using it to answer, and confirm that those questions are the ones now closed.

Then ask which other system's questions the same information would answer, and whether that system can still reach it after you dispose of it. Discard on the strength of a named system rather than a general impression of staleness, and where a second claimant is plausible, route the material to it instead of to the bin.
