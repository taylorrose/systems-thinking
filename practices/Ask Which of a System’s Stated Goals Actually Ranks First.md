# Ask Which of a System’s Stated Goals Actually Ranks First

When a system names several goals together, do not assume the stated sequence is the operating one. Find out which goal is measured, which is reviewed, and which absorbs effort when the goals compete.

The goal the system can inspect directly is the one most likely to be served first. Treat the announced ordering as a description of intent and the observed ordering as a description of the system.
