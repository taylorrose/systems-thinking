# Do Something Different When an Approach Is Not Working

Once an approach has shown that it is not working, stop repeating it. Change the method, the resources, the timing, or the problem itself so the next action is genuinely something else rather than another turn of the same attempt.

Judge the change by whether it creates a different result. If the same pattern continues, choose something else again instead of relabeling repetition as persistence.
