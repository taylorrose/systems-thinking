# Trace Each Indicator Back to the Condition It Measures

For each signal a system relies on, follow it back to its origin and name the physical or observable condition that drives it. Ask whether the signal would change if that condition changed, and whether it can change for any other reason — a command issued, a button pressed, a report filed.

Test the ones that matter by making the condition differ from the instruction and watching whether the signal follows the condition or the instruction. A signal that follows the instruction is reporting the system's own request and should not be counted as knowledge of the world.
