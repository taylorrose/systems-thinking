# Compare the Problems a System Solves with the Problems It Creates

Before creating or expanding a system, compare the original problem it is expected to reduce with the new problems required to operate, maintain, and adapt to it. Count burdens that change form or move elsewhere rather than treating the system's own requirements as external to the solution.

When effort is the useful common measure, [[explanations/Anergy Measures the Effort Required for Change|anergy measures the effort required for change]]. Compare the effort removed with the effort introduced.
